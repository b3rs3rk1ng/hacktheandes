# Hoja de cacao: generación del material

Archivo final: `cacao-leaf.png`. Herramienta integrada `image_gen.imagegen`; `transparent_background=true`. El PNG conserva alfa RGBA. No se usó el CLI ni una clave API externa. El material es generado y no constituye una fotografía botánica ni una anotación de enfermedad. No se utilizó para entrenar YOLO.

Prompt final exacto:

> Use case: photorealistic-natural. Create a production botanical texture asset for a realistic 3D cacao orchard simulator: ONE single mature healthy Theobroma cacao leaf, flat front-facing orthographic scan, vertically aligned, tip at top and a tiny stem at bottom. Entire leaf fully visible, centered, occupies 95% of image height and about 50% of image width. Authentic cacao botany: elongated elliptic oblong leaf, smooth entire margins, acuminate pointed tip, clearly visible pale midrib and 10-12 subtle curved lateral veins, deep forest green glossy leathery surface with fine photographic microtexture and a few natural subtle imperfections. Flat neutral diffuse illumination suitable for PBR albedo, no cast shadow, no highlights blown out, no perspective, no curls, no branches, no other objects, no text or watermark. Truly transparent background with clean alpha cutout. This is a texture for foliage meshes in a realtime robotics simulator, not a rendered tree or concept image.
