This project aimed to produce computer vision models capable of early disease detection in cocoa trees. 

The accompanying code can be found at the following Github repo: https://github.com/jrsykes/CocoaReader


The cocoa_disease_images.tar.gz dataset contains images of diseased and healthy cocoa scraped from the internet.

The EcuadorCocoa_EasyDificult.tar.gz dataset contails all of the images in the cocoa_disease_images.tar.gz dataset plus approximately 7,000 colour images of diseased and healthy cocoa collected from across Ecuador. These images are compressed to 500x500 pixels and organised into "Easy", "Difficult" and "Unsure" to accommodate a semi-supervised learning approach.

The Raw_Ecuador_images_11_03_23 1-4 zip files contain all images collected from Ecuador, uncompressed and unorganised.
