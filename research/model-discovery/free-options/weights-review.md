# Opciones gratuitas con pesos verificados

Verificado el 18 de octubre de 2026 UTC mediante APIs oficiales de GitHub y Hugging Face, originales del autor y descarga real de artefactos. Alcance: manzana, pera, durazno, nectarina, ciruela, albaricoque/damasco y frambuesa. Los candidatos contienen otras frutas, pero las únicas compatibles con el alcance que se recomiendan aquí son manzana y damasco.

**Sí existen modelos descargables gratis para experimentar. Ninguno de estos cuatro acredita uso industrial habitual en drones ni detección fiable de enfermedad del fruto durante vuelo.** Descargar pesos tampoco acredita inferencia correcta: no ejecuté repositorios, checkpoints ni modelos y no instalé paquetes.

Las métricas corresponden a tareas y poblaciones diferentes: **no forman un ranking comparable**. No evalué latencia, desenfoque, oclusión, cambios de luz, falsos retiros ni transferencia al simulador. El candidato de damasco es el más cercano de estos cuatro a una enfermedad nombrada; el de AKASH ofrece la pieza más directa para localizar manzanas deterioradas. Ninguno puede describirse aún como excelente para el dron solicitado.

## Evidencia técnica reproducible

Los archivos y respuestas originales están en [weights/](weights/). [Manifiesto de cuatro artefactos](weights/download-manifest.json) registra URL con revisión fija, bytes y SHA-256. La descarga de damasco tiene [manifiesto propio](weights/apricot-download-manifest.json): HTTP Range permitió leer el índice del ZIP de 843,703,864 B y recuperar únicamente el MobileNet comprimido (~5.74 MB), sin descargar el archivo completo. Se verificaron tamaño y CRC del miembro ZIP.

- [Metadatos ONNX](weights/akash_onnx_metadata.json): la licencia AGPL-3.0 y las etiquetas están dentro del modelo. Fuente: [ONNX original](https://github.com/AKASH-ALAM/Fruit_Quality_Detection_Using_Deep_Learning/blob/main/model/fruit_quality/weights/best.onnx), [reporte de evaluación](https://github.com/AKASH-ALAM/Fruit_Quality_Detection_Using_Deep_Learning/blob/main/classification.txt).
- [FruitNet: inferencia y clases](https://github.com/OleksandrKlanovets/fruitnet/blob/master/model/fruitnet.py), [H5 original](https://github.com/OleksandrKlanovets/fruitnet/blob/master/config/fruit_classifier_v3_transfer_learning.h5), [licencia](https://github.com/OleksandrKlanovets/fruitnet/blob/master/LICENSE).
- [ausjahk: config y clases](https://huggingface.co/ausjahk/fruits-fresh-rotten-from-scratch/blob/main/config.json), [ficha/licencia/evaluación](https://huggingface.co/ausjahk/fruits-fresh-rotten-from-scratch/blob/main/README.md), [peso](https://huggingface.co/ausjahk/fruits-fresh-rotten-from-scratch/blob/main/model.safetensors).
- [Damasco: release con checkpoints](https://github.com/amaniqbal-ai/apricot-disease-classification/releases/tag/v1.0), [config de clases y resultados](https://github.com/amaniqbal-ai/apricot-disease-classification/blob/main/src/config.py), [licencia](https://github.com/amaniqbal-ai/apricot-disease-classification/blob/main/LICENSE). Las cadenas embebidas del checkpoint usan espacios (`brown rot`); la config usa guiones bajos (`brown_rot`), en el mismo orden. Requiere normalizar la presentación, sin tratarlo como enfermedad distinta.

Descarté como opción lista otro [clasificador de sarna del fruto de manzana](https://github.com/ayushdabra/apple-scab-disease-classification): el árbol no incluye pesos entrenados; publica notebooks y 85.71% sobre sólo 28 imágenes, y el README declara que usa el mismo test como validación durante el entrenamiento. El dataset además se declara CC BY-NC-ND 4.0. No cumple con ofrecer aquí un checkpoint gratuito verificado y evidencia sólida para el uso pedido.

Los PT se inspeccionaron como ZIP y con `pickletools` para leer cadenas, sin `pickle.load` ni `torch.load`; el ONNX se leyó como estructura protobuf; el safetensors se revisó como cabecera JSON/offsets; el H5 sólo por su firma. Esto confirma artefactos reales, no su calidad predictiva ni su ejecución. Los binarios son evidencia local y no se publicaron ni se modificó el simulador.
